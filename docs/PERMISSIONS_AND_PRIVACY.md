# Permissions & Privacy Policy

## Core Privacy Principles

1. **Offline-First Location Processing:**
   - All geographical coordinate calculations, distance measurements, and alarm triggers occur strictly on-device.
   - Pingoo does NOT transmit user locations, saved destinations, or journey histories to external servers or cloud services.

2. **No Unnecessary Permissions:**
   - Only location permissions (`ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`) are requested for core GPS alarm features.
   - No SMS, contacts, microphone, camera, or broad file storage permissions are requested.

3. **No Full-Screen DND/Battery Exemption Abuse:**
   - Pingoo operates within standard Android background and notification guidelines.

4. **No Third-Party Analytics / Tracking:**
   - Pingoo contains zero advertising SDKs, tracking libraries, or mandatory cloud dependencies.
