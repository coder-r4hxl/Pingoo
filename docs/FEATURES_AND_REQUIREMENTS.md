# Pingoo Features and Requirements

## Completed Features
1. **Offline GPS Destination Alarms:** Configurable arrival radius (50m - 50km) and advance warning thresholds.
2. **Multi-Stop Route Builder:** Staging, reordering (up/down), and managing ordered stops for train and bus routes.
3. **Automatic Stop Progression:** Advances to the next stop only after arrival acknowledgment.
4. **Full-Screen Lock-Screen Overlay:** `AlarmActivity` launches with audio ringtone, vibration, snooze, and dismiss.
5. **Interactive Map Picker:** OSMDroid map selection with tap pin placement and reverse geocoding.
6. **Local Journey History:** Logs completed/stopped journeys with date, duration, and stops reached ratio.
7. **Bilingual UI:** Instant runtime switching between English and Hindi.
8. **Privacy-First Storage:** Local Room database v3 and DataStore preference storage.
