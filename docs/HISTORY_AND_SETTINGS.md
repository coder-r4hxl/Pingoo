# History and Settings Documentation

## Features
- **Journey History:** Room DB v3 logs completed and stopped journeys with date, duration, and reached stops ratio.
- **Preferences:** DataStore preferences store language (`en`/`hi`), vibration toggle, default arrival radius, and configurable snooze duration (5, 10, 15 mins).
- **Privacy Controls:** Settings screen includes Privacy Policy disclosure and clear local data controls.
